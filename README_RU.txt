Ticket Monitor — мобильное приложение (mobile 1.0)

Это веб-приложение (PWA). Его нужно один раз выложить на хостинг (HTTPS), потом
каждый сотрудник открывает ссылку в телефоне и добавляет на главный экран.

Выложить (вариант GitHub Pages, бесплатно):
 1. github.com → New repository → имя ticket-monitor-app → Public → Create.
 2. Add file → Upload files → перетащить ВСЕ файлы из этой папки (вместе с папкой icons) → Commit.
 3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
 4. Через 1–2 минуты адрес: https://<имя>.github.io/ticket-monitor-app/
 В коде нет паролей и данных: config.js содержит только адрес базы и публичный ключ.
 Без входа сотрудника из базы ничего прочитать нельзя.

Установить на телефон:
 iPhone: открыть ссылку в Safari → «Поделиться» → «На экран Домой».
 Android: открыть в Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
 Вход — тот же e-mail и пароль, что в программе на компьютере.

Обновление: заменить файлы в репозитории; телефоны получат новую версию при следующем открытии.
